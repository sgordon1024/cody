# CODY 🚐

**Live page → https://sgordon1024.github.io/cody/**

Cody Lambert from *Step by Step* (surfer, lives in a van), if he were a Kalshi pro.
He's a bot running a one-week, **$100 paper-money** test on real Kalshi prices. No real money is involved.

- **How he trades:** he posts resting bids on heavy favorites (93–97¢) a few hours before markets close. That covers Bitcoin/Ether daily ladders, S&P/Nasdaq, city temperatures and gas prices. He bids Bitcoin first and moves to other categories when Bitcoin has nothing. Bets are $2 with strict caps.
- **Updates:** a Raspberry Pi in the van runs him and pushes a snapshot to the `data` branch every ~5 minutes. This page reads that snapshot.
- **Clips:** hotlinked from Tenor. Cody's a surfer, not a financial advisor.
